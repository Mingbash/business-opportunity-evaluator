# Changelog

## 0.2.1 (unreleased)

The skill is now named `idea-validation`. The old `business-opportunity-evaluator` name remains available as an independently installable compatibility copy. Evaluation rules are unchanged. The bilingual README and quick starts use the new name; existing repository URLs and release archives are preserved.

## 0.2.0 — 2026-11-10

Broad ideas now become a shortlist of concrete businesses. The evaluation compares them against the same goal and resources, then explains what to test first. A different way to reach the same buyer stays within the same business. The bilingual guides now include the historical website case and explain the short and full outputs.

## 0.1.0 — 2026-11-09

First public release. Includes standalone skill packages, Chinese and English guides, and worked examples. The READMEs show what to paste into a chat and what each skill returns. See [validation](docs/VALIDATION.md) for the tested environments.
