# Generalization ledger

| Area | Keep | Change |
|---|---|---|
| Decision method | Atomic business; original vs repair; eight dimensions; three tiers | State limits when current source tools are unavailable |
| Market scope | Theoretical, serviceable and reachable capacity are distinct | Infer geography from business; no mandatory global or home-country scope |
| Scores | Evidence gates, U for unknown, confidence separate from tier | Default weights are adjustable judgment assumptions; missing proof alone does not force a numeric low score |
| Output | Readable decision/evidence/assumption separation | Markdown default for any count; optional CSV/workbook |
| Language | Respond in user's language | English Agent UI metadata plus English/Chinese usage docs |
| Regression suite | Original R1–R6 and H1–H18 intent | R2 reconciles U semantics; add local-service/offline/weight tests |

No public API or runtime dependency is added. This remains a portable instruction package. Changes preserve user-specified buyer, offer, revenue and original acquisition route before proposing repairs.
